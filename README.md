Задание 1 — Студенты

Создан класс Student с полями: ФИО, группа, курс, оценки по предметам.
Реализованы методы:

расчёт среднего балла;

перевод на следующий курс (если средний балл ≥ 3);

отметка студентов со средним баллом < 3 как отчисленных;

вывод студентов, обучающихся на указанном курсе.

Задание 2 — Телефонный справочник

Реализован класс PhoneBook, который хранит фамилии и несколько телефонных номеров для одного человека.
Методы:

add() — добавление нового номера;

get() — вывод всех телефонов по фамилии (учёт однофамильцев).
